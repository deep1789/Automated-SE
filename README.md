# Abstain Before You Trust: risk-controlled triage for automated vulnerability detection

Manuscript, code and results for a study of when an automated vulnerability detector can be trusted to *clear* code.
Conformal risk control gives a finite-sample bound on the share of vulnerable functions that are auto-cleared; we test it on
DiverseVul and Big-Vul under random, project-disjoint, temporal and cross-dataset splits.

* `paper/main.tex` (Elsevier `elsarticle`, target: Journal of Systems and Software special issue on Reliable and Trustworthy ASE) and `paper/main.pdf`
* `src/triage.py` – conformal clearance, PAC variant, weighted/Mondrian variants, certified flagging, metrics
* `src/prep.py`, `feats.py`, `run_models.py` – data audit, features, detectors; `analyze.py`, `robust.py`, `explain.py`, `flaw_baseline.py` – experiments
* `src/make_tables.py`, `make_figs.py`, `make_figs2.py` – every table/figure in the paper is generated from `results/*.csv|json`
* `tests_triage.py` – unit tests and a finite-sample validity simulation
* `results/*.csv|json` – final result tables (cached per-function scores are regenerated by `run_all.sh`)

Reproduce: `./run_all.sh` (CPU only). Data: Hugging Face `claudios/DiverseVul`, `bstee615/bigvul`.
